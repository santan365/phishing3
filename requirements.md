# Functional Requirements (MVP)
- FR-1: Start training from Home.
- FR-2: Display one SMS scenario (sender, time, body, URL preview).
- FR-3: User chooses PROCEED or REPORT.
- FR-4: Immediate feedback (correct/incorrect + 2–3 cues + tip).
- FR-5: Score persists locally (localStorage). *(Week 2)*

# Non-Functional Requirements
- NFR-1: Responsive on mobile and desktop.
- NFR-2: Accessible controls (large buttons, contrast).
- NFR-3: View change < 1s on common hardware.
- NFR-4: No PII stored; offline-capable once loaded (stretch).
